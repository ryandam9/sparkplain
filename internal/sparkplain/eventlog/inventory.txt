# Field inventory (SPEC §8, phase 1c). Every event and field Spark 3.5 (and EMR)
# writes is listed with what sparkplain does with it:
#   used          read, and shown in the report or explorer
#   aside         deliberately not read; the note says why
#   planned:N     to be read in phase 1c step N
# Paths use / for nesting, [] for array elements and /* for maps whose keys
# are data (settings, properties, rule names). A plan node's children have
# the same fields as the node. TestFieldInventory fails on any field a
# fixture holds that is not listed here; parsing counts unlisted fields as
# unknown so newer Spark releases show up.
